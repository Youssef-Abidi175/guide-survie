# Guide de Survie — Dauphine Tunis

Un petit site qui rassemble les conseils pratiques qu'on aurait aimé
recevoir en arrivant sur le campus.

Ce dépôt est le support du module **Git & GitHub**. Vous n'avez pas à
savoir développer pour y contribuer : chaque modification à faire vous
est donnée mot pour mot dans l'énoncé du TP.

---

## Ouvrir le site

Double-cliquez sur `index.html`. Il s'ouvre dans votre navigateur. Il n'y a rien à installer, rien à compiler, aucun serveur à lancer.

Après chaque modification, enregistrez le fichier et rafraîchissez la page du navigateur (`F5`, ou `Cmd + R` sur Mac).

---

## Ce que contient le dépôt

| Fichier | À quoi il sert |
|---|---|
| `index.html` | La structure de la page : le titre, le menu, le pied de page |
| `css/style.css` | Les couleurs, les polices, la mise en forme |
| `data/fiches.js` | **Le contenu des fiches.** C'est ici que vous écrirez le plus |
| `js/script.js` | Le code qui affiche les fiches à l'écran |
| `images/` | Vos images, si vous en ajoutez |
| `defis.md` | Les fonctionnalités bonus, pour aller plus loin |
